## 🏛️ What is ChronoQuest?

ChronoQuest reimagines history education as an **interactive narrative RPG**. Instead of passively consuming dates and facts, you step into the shoes of historical decision-makers, face the moral weight of pivotal moments, and earn your place in the timeline.

Built as a **full-stack Next.js application with TypeScript**, ChronoQuest combines cinematic storytelling, branching decision trees, and a robust XP progression system to make learning history feel like the epic it truly is.

> *"Step onto the battlefield at Kalinga. Feel what Ashoka felt. Then decide: do you march forward — or lay down your arms?"*

---

## ✨ Features

### 🎮 Cinematic Story Campaigns
Narrative-driven modules that place you at the heart of history's most defining moments. Each campaign is crafted as a branching story — your choices shape the path forward, not just your score.

### 🧠 Knowledge Checks with Consequences
Embedded quiz mechanics tied directly to the narrative. Answer correctly to unlock the next scene. Every question is contextual — grounded in the story you just experienced, not lifted from a textbook.

### ⚡ XP & Leveling System
A full progression engine with experience points, player levels, and ranked titles (starting at **Vanguard**). Every correct answer, every completed campaign, every daily challenge pushes you further up the leaderboard of history.

### 🔥 Daily Streak System
Show up every day. Build your streak. ChronoQuest rewards consistency — because mastery of history is built over time, not in a single session.

### 📋 Command Deck Dashboard
A sleek, real-time personal dashboard showing your level, total XP, daily streak, and progress toward the next rank — all at a glance, every time you return.

### 🏆 Daily Challenges
Fresh challenges served every day to keep your knowledge sharp and your streak alive. Dynamically surfaced to match your current progression level.

### 🌿 Branching Narrative Decisions
Two paths always lie before you. Do you *"Walk through the battlefield and meet survivors"* — or *"Prepare to expand the empire further"?* Every choice is meaningful, every path teaches something different.

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| **Framework** | Next.js 15 (App Router) |
| **Language** | TypeScript (97%+ codebase) |
| **Styling** | CSS Modules + PostCSS |
| **State Management** | Custom store architecture (`/store`) |
| **Data Layer** | Structured data modules (`/data`) |
| **Type Safety** | Centralized type definitions (`/types`) |
| **Utilities** | Shared lib layer (`/lib`) |
| **Deployment** | Vercel |

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm / yarn / pnpm / bun

### Installation

```bash
# Clone the repository
git clone https://github.com/Akkshita06/ChronoQuest.git
cd ChronoQuest

# Install dependencies
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm start
```
